# Thought Dump

**Thought Dump** is a minimal, anonymous space to unload what’s on your mind.  
Write it. Send it. Let it go.  
You won’t see it again.

🌐 Website: https://www.thoughtdump.in  
📩 Support: support.thoughtdump@gmail.com  

---

## About the Project

Thought Dump is built around one simple idea:

> Some thoughts are meant to be released, not revisited.

Once a thought is submitted, it disappears forever for the sender.  
No profiles. No history. No pressure.

---

## Tech Stack

This project is built using:

- Vite  
- TypeScript  
- React  
- Tailwind CSS  
- shadcn/ui

## Running the Project Locally

### Prerequisites
- Node.js (recommended via nvm)
- npm

### Setup

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Move into the project folder
cd thought-dump

# Install dependencies
npm install

# Start the dev server
npm run dev
The app will be available at http://localhost:5173 (or the port shown in terminal).

Deployment
The project is deployed using Vercel.
Any push to the main branch triggers an automatic redeploy.
